Set up this phone

This page updates the TSC app for you. It needs a GitHub key (made once on your computer) and a PIN you choose for this phone.

The key is kept on this phone only, locked with your PIN. It is never sent anywhere except GitHub.

How to make the GitHub key (once, on your computer)
  1. Sign in to GitHub as TooleybucApp, then open github.com/settings/personal-access-tokens/new.
  2. Token name: TSC admin – John's phone. Expiration: 1 year (or the longest allowed).
  3. Repository access: Only select repositories › TooleybucApp.github.io.
  4. Permissions › Repository permissions › Contents › Read and write. Leave everything else as it is.
  5. Press Generate token and copy it (it starts with github_pat_). Send it to your phone yourself (e.g. a note or email to yourself) – don't send it to anyone else.
  6. Lost the phone? On GitHub › Settings › Developer settings › Fine-grained tokens, delete the key. It stops working at once.
